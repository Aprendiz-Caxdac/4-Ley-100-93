Recaudos por Devolver

Esta ventana se alimenta manualmente, y guarda los recaudos sin identificar del PILA o pagos no correspondientes a CAXDAC (No vinculados) por terceros.

Al dar doble clic sobre la descripción del tercero, se puede validar la información correspondiente al cotizante. El sistema genera la siguiente validación.

Al dar clic en Si, muestra la información básica del cotizante, como se muestra en la siguiente ilustración:

Hacer Ingreso Contable: Se utiliza para generar la contabilización del pago no correspondiente ingresado, arrojando un número de pre documento contable, este debe pasar a documento y para ello se debe ingresar al aplicativo de Contabilidad.

Hacer Giro Contable: Se utiliza para generar la contabilización del pago no correspondiente Devuelto, arrojando un número de pre documento contable, este debe pasar a documento y para ello se debe ingresar al aplicativo de Contabilidad
