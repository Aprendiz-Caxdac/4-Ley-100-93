Tasas Moratorias

Las Tasas Moratorias son las tasas que el sistema utiliza para calcular los intereses de mora cuando existen aportes pagados fuera de los plazos establecidos.

{img}

Tasas Moratorias Sistema Antiguo

Las Tasas Moratorias del Sistema Antiguo existen porque el sistema actual mantiene dependencias internas con el esquema anterior.

{img}

Nuevas Tasas Moratorias

Las Nuevas Tasas Moratorias sirven para que el sistema tenga registrada la tasa que utiliza en el cálculo de los intereses de mora asociados a los aportes de Ley 100.

{img}

Ingreso de Tasas

Sirve para registrar mensualmente la tasa de usura que el sistema utiliza para el cálculo de intereses de mora asociados a los aportes.

{img}

Tipos de Tasas

Permite consultar y diferenciar los tipos de tasas que maneja el sistema para intereses moratorios.
